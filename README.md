# cybersecurity-notes
For any new users, when logged in Kali, First in desktop there will be two folder called Home and File System. Home is the user's folder where downloads,music including desktop will be there. Icon of this location is ~
And File system folder is root, where main system file of kali is there and the icon of this is /

Linux has no separate drive letters like C: or D:. Everything is organized in one single directory tree that starts at the root folder, written as /. All the system files, programs, user data and even other storage devices live inside this one tree.(One single storage)

When you add another disk or USB drive, Linux doesn't give it a new letter. It mounts the drive into a folder inside the tree (for example, /mnt or /media), and you access it like any other directory.
