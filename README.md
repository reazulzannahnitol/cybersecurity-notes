# cybersecurity-notes
For any new users, when logged in Kali, First in desktop there will be two folder called Home and File System. Home is the user's folder where downloads,music including desktop will be there. Icon of this location is ~
And File system folder is root, where main system file of kali is there and the icon of this is /

Inside File system root folder (/) there are all root main system file/folders of linux (there is no c,d drive!) all storage
inside here in single drive and that is linux)
